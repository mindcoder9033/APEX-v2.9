Forza Telemetry UDP Setup Guide

To stream live telemetry from Forza Motorsport 2023 or Forza Horizon 5 into APEX, enable Data Out in your game settings:

1. Open In-Game Settings

Navigate to: Settings ➔ Gameplay & HUD ➔ Scroll down to the Data Out section.

2. Configure Data Out Parameters
DATA OUT ON
PACKET FORMAT CAR DASH
IP ADDRESS 127.0.0.1 (or LAN IP)
DATA OUT PORT 9999
💡 Xbox to PC Setup: If playing on an Xbox console, set the Data Out IP Address to your PC's local network IP (e.g. 192.168.1.xxx), ensuring both devices are on the same Wi-Fi / LAN.
